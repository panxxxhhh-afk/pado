서버 주소

서버가 아직 없어요

계정을 나눠 주려면 pAdo 서버가 먼저 있어야 해요. 아래 순서대로 한 번만 하면 돼요.

  1. Cloudflare 무료 계정 만들기
    dash.cloudflare.com/sign-up 에서 전자우편으로 가입해요. 돈은 들지 않아요.
  2. 서버 올리기
    이 컴퓨터에서 터미널(Windows는 Git Bash)을 열고 websurfer 폴더로 간 뒤 아래 명령을 실행해요. 차례로 ① Cloudflare 로그인 ② 관리 암호 ③ 가입 코드(선택) ④ AI 키(console.anthropic.com → API Keys 에서 만든 것)를 물어봐요.
    bash sync/deploy.sh
  3. 공개 페이지에 올리기
    같은 폴더에서 아래 명령을 실행하면 이 페이지가 새 서버 주소를 알게 돼요.
    bash deploy-pado.sh
  4. 이 페이지 새로 고침
    서버 주소가 저절로 채워져요. 관리 암호만 넣고 [연결]을 누르면 돼요.

자세한 안내: websurfer 폴더의 sync/README-설정.md
