입 모양 그림 — 한글에 없는 소리 셋

글자소리비슷한 한글 소리와 다른 점견주기
ㆄfㅍ처럼 시작하지만 입술을 다물지 않아요 — 윗니를 아랫입술에 살짝 대고 바람만파인(pine) ↔ ᅗᅡ인(fine)
ㅸvㆄ f와 같은 입 모양에서 목만 울려요 — ㅂ처럼 입술을 다물지 않아요밴(ban) ↔ ᄫᅢᆫ(van)
ㅿzㅅ 자리(혀끝을 윗잇몸 가까이)에서 목만 울려요 — ㅈ이 아니에요수-(sue) ↔ ᅀᅮ-(zoo)
ㆄ·ㅸ는 ㅍ·ㅂ 아래에 ㅇ을 이어 쓴 글자예요(연서). 훈민정음은 이렇게 쓰면 입술을 가볍게 내는 소리(순경음)가 된다고 했고, pAdo는 그 작은 ㅇ을 "바람이 샌다"는 표시로 읽어요.
ㅿ는 세종 때부터 있던 ㅅ 계열 글자예요(반치음) — ㅇ을 이은 글자가 아니에요.
모음이 뒤따르면 ᅗᅡ처럼 붙고, 끝이나 자음 앞에선 ㆄ처럼 홀로 서요 — 같은 글자예요. 홀로 선 ㆄ·ㅸ·ㅿ는 받침이 아니라 따로 나는 소리예요('으'를 붙이지 않아요).
f·v·z는 다른 영어 글자와 붙어 있어도 바뀌어요: from 「ㆄr엄」 · left 「레ㆄt」. 「five」처럼 한글이 하나도 없는 영어 인용은 그대로 둬요.
r·th·끝의 k·s·t는 이번에는 영어 글자 그대로 둬요 — 이 세 글자로는 적을 수 없고, 끝소리를 한글 받침으로 쓰면 소리가 달라져서예요. r은 입술을 '우'처럼 오므리고 혀는 어디에도 닿지 않게, th는 혀끝을 이 사이에 살짝 내밀고 바람.
괄호 (드)는 있는 듯 없는 듯 작게 — 1908년 지석영의 『아학편』이 영어 소리를 적을 때 작은 글자로 쓰던 것과 같은 뜻이에요.
알아 두기: 받침 ㅇ은 원래 세종의 ㆁ(옛이응)이에요. 세종 때 ㆄ·ㅸ는 두 입술 소리였고 영어 f·v는 윗니 소리라 꼭 같진 않아요 — 진짜 소리는 🔊 읽어 주기로 들어요. 이 글자는 읽는 용도예요 — 영어나 한국어 글을 쓸 때는 쓰지 않아요.
출처: 1446 훈민정음 해례(연서: ㆄ·ㅸ) · 1948 문교부 「들온말 적는 법」(ㆄ=f·ㅸ=v·ㅿ=z). 표준 표기(외래어 표기법)가 아니라 학습용 근사치예요. AI는 이 글자를 쓰지 않아요 — 앱이 화면에서 그려요.

    ⚙️ 설정

    요금의 대부분은 답 쪽에서 나와요 — 무엇이 얼마나 들었는지는 위 줄(이 기기 집계)에서 봐요.
    바뀐 것 ① 대화 이력도 캐시에 올려요 — 다음 턴부터 입력 단가의 1/10~1/20 값으로 읽어요(모델마다 달라요 · 5분 안에 이어 쓰면 유지). ② 튜터·작문·번역·상황극·시험에서는 AI가 생각을 짧게 해요. 질문·분석·코치는 보통으로 둬요. ③ 🗣 말하기 턴도 지시문을 캐시로 읽어요.
    얼마나 아꼈는지는 위 줄의 '캐시로 아낀'과 '답 중 생각이 차지한 비율'로 확인해요. 설명이 얕아졌다고 느끼면 '그대로'로 — 생각 길이만 원래대로 돌아가고 캐시는 유지돼요. 더 아끼려면 '알뜰' — 튜터·작문·번역·상황극·시험만 Sonnet 5.5로 보내요. 숫자는 이 기기의 추정이고 실제 청구는 Anthropic 콘솔이 기준이에요.
    새 모양은 색·글꼴·간격이 차분하게 바뀐 모양이에요. 오늘 할 일은 🌊 오늘과 메인 화면(왼쪽 위 pAdo 로고)에서 봐요. 기록·설정은 두 모양이 같이 써요. 밝기는 고른 적이 없으면 밝게예요(자동은 기기 설정을 따라요). 이 설정은 이 기기에만 저장돼요.
    "바람 소리, 학 울음, 닭 울음, 개 짖는 소리까지 적을 수 있다" — 훈민정음 해례본, 정인지의 글(1446). 세종은 글자 스물여덟 개만이 아니라 글자 만드는 법도 남겼어요. ㅍ·ㅂ 아래 ㅇ을 이어 쓰면 입술을 가볍게 내는 소리(ㆄ·ㅸ), 그리고 세종 때부터 있던 ㅿ — 이 셋을 f·v·z 자리에만 빌려 와요.
    소리를 눈으로 구분해 보는 실험 표기이고 표준 표기(외래어 표기법)가 아니에요 — 한글 표기는 늘 근사치예요. r·th는 이 글자들로도 못 적어 영어 글자 그대로예요. 소리는 설정과 상관없이 영어 글자를 섞은 원래 표기로 읽어 줘요. 2단계부터 글 속 「한글 소리」가 나올 때마다 보여요(1단계는 입 모양 그림만). 다른 앱에 붙여 넣으면 깨져 보일 수 있어요.
    이 브라우저에 설치된 목소리 중에서 골라요 — 기기마다 달라요. "인터넷 필요"는 소리를 만들 때 브라우저 회사 서버를 쓰는 목소리예요. 윈도우에선 엣지 브라우저의 목소리(SunHi·Aria)가 가장 자연스러워요.

    켜면(기본) 말을 멈추고 생각해도 듣기를 끝내지 않아요 — "여기까지"·"이상입니다"(영어는 "that's all")라고 하거나 🎙을 다시 누를 때만 마무리돼요. 끄면 이전 방식: 말이 잠깐 끊기면 자동으로 마무리(말하기 튜터는 1.5초 뒤 보내요). 이 설정은 이 기기에만 저장돼요.
    가입하면 학습 기록·대화·설정이 계정에 저장되고, 어느 기기에서든 같은 아이디로 로그인하면 그대로 이어져요. API 키가 없어도 계정으로 AI를 쓸 수 있어요(서버에 키가 있을 때). 비밀번호·API 키는 다른 기기로 전송되지 않아요. 새 계정은 빈 기록으로 시작해요.
    회원가입 때 받는 복구 코드로 비밀번호를 되찾을 수 있어요 — 가입 정보(이름·전화번호)는 운영하는 분만 봐요.
    복구 코드가 아직 없어요 — 비밀번호를 잊었을 때를 위해 [복구 코드 만들기]를 눌러 적어 두세요.
    🔧 서버 주인이신가요? 친구에게 줄 계정은 계정 발급 페이지에서 만들어요.
    🔧 고급 — API 키 · 모델 · AI 역할 지시문 · 기기 이사
    키는 이 브라우저에만 저장되고, Anthropic API 호출에만 쓰입니다. pAdo 서버로는 보내지 않아요(📦 이사 코드를 만들면 그 코드 안에는 들어가요). 키 발급: console.anthropic.com → API Keys · 키가 없어도 아래 👥 계정에 로그인하면 계정으로 AI를 쓸 수 있어요(서버에 키가 있을 때).
    AI 답은 틀릴 수 있어요 — 중요한 표현은 한 번 더 확인해요.
    이 앱의 AI가 "영어 튜터"처럼 행동하는 이유가 바로 이 지시문입니다 — 매 질문마다 함께 전송돼요. 자유롭게 수정하세요. 비우고 저장하면 기본값으로 돌아갑니다.
    🔍 지금 이 대화에 실리는 지시문 전체 보기
    위 지시문에 학습 설정이 더해져 AI에게 전해져요 — 단어 대화에는 단계·난이도·방식·목표, 파도에는 단계·난이도, 🧭 파도 Chat에는 단계만 실려요(코치는 진단·계획이 일이라 방식·목표는 싣지 않아요). 내 약점·이 단어의 맥락도 더해져요. 숨기는 내용은 없어요.
    
  
  
    대화가 길어져 창 밖으로 밀린 부분을 pAdo가 뒤에서 조용히 요약해 두고 매 질문에 함께 보내요 — "초반은 기억에서 지워졌어요"가 줄어듭니다. 요약할 때 API 호출이 한 번 더 나가요(비용 조금). 푼 문제 기록은 이 설정과 무관하게 항상 남아요.
    
  
  
    API 키·학습 기록(오늘의 복습)·대화·설정 전부를 코드 하나로 묶어요. 옮기는 법: ① 지금 쓰던 기기에서 [이사 코드 만들기] → [복사] ② 메일이나 메신저의 "나에게 보내기"로 다른 기기에 전달 ③ 그 기기에서 코드를 복사해 이 칸에 붙여넣고 [가져오기]. ⚠️ 코드 안에 API 키가 들어있어요 — 다른 사람에게는 절대 보내지 마세요. 단, 로그인 정보는 옮겨지지 않아요 — 새 기기에서 같은 아이디로 로그인하면 이사 없이도 PC와 폰이 이어져요.
